# Apex V5 — Planejamento por áreas

- `Agenda e metas` renomeado para `Organize sua rotina`.
- `Hábitos` renomeado para `Crie novos hábitos`.
- `Metas de longo prazo` virou um bloco próprio no topo de Planejamento.
- `Projetos de leitura` virou o bloco `Biblioteca de leitura`.
- Cada bloco exibe somente o conteúdo relacionado.
- Os quatro blocos formam uma grade responsiva no desktop e tablet.
